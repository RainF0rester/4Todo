# TaskTracker Frontend

Frontend application for TaskTracker built with **Vue 3 + Vite + Vue Router**.

---

## Tech Stack

- Vue 3
- Vite
- Vue Router

---

## Getting Started (Mac)

### 1) Prerequisites

Install **Node.js (LTS recommended)** from:
- https://nodejs.org

Verify:

```
node -v
npm -v
```

Both commands should return version numbers. If you see a version number (for example v18.x.x), the installation was successful.

### 2) Install Dependencies
```
npm install
```


### 3) Start the Development Server
```
npm run dev
```
