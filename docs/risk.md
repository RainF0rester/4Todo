# Risk report (Sprint 3)

## How to use this template

- Replace all placeholder text and remove this instruction section if you prefer.
- Aim for about **three meaningful** risks. Delete unused sections or duplicate a risk block if you need more.
- Copy this file into your **group repository** as e.g. `RISK_REPORT.md` in the **repo root**, then fill it in. **Link the report from your root `README.md`**.
- **Risk statement:** use _If [cause happens], then [bad outcome] because [reason]_ where you can.
- **Evidence:** point to something other people can verify (file path, test name, MR link, issue `#`, commit hash).
- **Traceability:** in GitLab, you can mention a risk in an MR or issue (e.g. “Mitigates R2”).
- Fill the small table below to map risks to issues/MRs.
- Requirements match **Sprint 3 §4.2** and **Lecture 8.1**. Every risk must include **evidence** and **status** (and the other fields below).
