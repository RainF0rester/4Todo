# Our Contribution Rules

## Branch Name Rules

### format

``type/short-description``

### types

- `feat/` - new features
- `fix/` - fix bugs
- `docs/` - documents changes
- `chore/` — maintenance (deps, scripts, configs)
- `refactor/` — refactoring (no behavior change)
- `test/` — tests

### example

``feat/add-task-function``

## Commit Message Rules

### format

``type(scope): short summary``

P.S. scope is optional

### types

- **feat**: New feature
- **fix**: Bug fix
- **docs**: Documentation (README, docs, comments, etc.)
- **refactor**: Refactoring (no behavior change)
- **test**: Testing-related changes
- **chore**: Maintenance(dependencies, scripts, CI, configuration)

### example

``feat(backend): add task feature``

## Merge Requests Rules

All MRs must be:

- Approved by someone else on the team (peer review).
- Merged by the author after approval.
